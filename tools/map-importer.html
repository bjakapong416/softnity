นำเข้าเกม

ทาง ก (ในเกม): ตั้งค่า → แผนที่เมืองจากไฟล์ → เลือกภาพแผนที่ + JSON → ใช้แผนที่นี้
ทาง ข (GitHub): อัปโหลดไฟล์ไว้ในโฟลเดอร์ maps/ แล้วสร้าง maps/manifest.json: 
{ "town": { "png": "maps/town.png", "json": "maps/town.json" } }
แนะนำ: ภาพแผนที่ควรกว้าง 2,000–4,000 พิกเซลขึ้นไปให้ภาพคม และ 1 ช่องตารางควรกว้างประมาณครึ่งหนึ่งของความสูงตัวละครในภาพ
